# 制药企业洁净区与批生产记录管理平台

面向洁净区环境监测、批生产记录编录、物料放行、偏差与变更控制、灭菌与清洁验证、成品检验与年度质量回顾的一体化药品生产质量管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

留样台账相关规则集中在 `frontend/src/api/retain.ts`（页面不做业务判断）：

- **按留样期限分册**：固定「6个月 / 1年 / 2年 / 3年 / 5年」每期限一册，册名标期限，册内写明
  留样编号、留样数量、存放条件、对应批号；各册打成一个 ZIP 可立即下载，同时发库房、车间两处。
  某期限没有在存留样时补一页说明页，不会只给表头的空壳册；一份在存留样都没有时整体拒绝导出。
- **销毁核准与签字**：状态一节一节流转
  `待留样 → 在存 → 已到期 → 待销毁核准 → 待销毁 → 已销毁`，跨级操作直接拒收；
  销毁前必须经质量部核准（填核准人）、办理销毁必须有经手人签字，缺签缺核准一律挡回。
- **重复导出只算一次**：同一留样编号重复出现在后续导出批次里计入「重复」，不重复累计已下发份数。
- **联动稳定性考察**：在流留样（生效版）按批号开出稳定性考察待办，建立考察后标记为已反映。
- **同一套存放条件**：登记、台账、稳定性考察都取 `data/retain-catalog.ts` 这一份档案
  （常温/阴凉/冷藏/冷冻，含温区与单份数量上限）；实测温度越界或留样数量超限在登记时即挡回。
- **版本优先级**：同一留样编号存在多版时，留样数量与留样期限以数据优先级高的一版为准，
  优先级平手取后登记（id 大）的一版；台账、分册与稳定性待办都只取生效版。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`；留样台账专有规则（分册、销毁核准、版本优先级、稳定性待办）
  在 `frontend/src/api/retain.ts`，统一存放条件与期限册序在 `frontend/src/data/retain-catalog.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在服务层改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `pharma-cleanroom:entries:v2` 这一项（导出批次记录在
  `pharma-cleanroom:aux:retain-export-log`），或在留样页点「恢复示例数据」/ 调用 `resetModule(模块)`。
